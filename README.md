# Portfolio — Sandiarivelo Mizason Rakotonindrina

Site statique (HTML/CSS/JS, sans build) présentant mon profil de développeur .NET / C#.

## Déploiement sur Render

1. Render → **New** → **Static Site** → connecter ce dépôt.
2. Build Command : laisser vide. Publish Directory : `.`
3. Chaque push sur la branche principale redéploie le site.

Le fichier `render.yaml` permet aussi un déploiement via **New → Blueprint**.
