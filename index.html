Moderniser une plateforme bancaire sans repartir de zéro

MyAccès regroupe les bots bancaires Messenger et Viber d’AccèsBanque et leur backend. J’ai mené sa refonte complète vers .NET 9.

Avant

  • .NET Framework
  • Bot et backend dans la même application
  • Ancienne structure de base de données

Après

  • .NET 9 et C# moderne
  • Clean Architecture (template Ardalis)
  • Bot et backend séparés en microservices
  • EF Core sur SQL Server, base migrée vers la nouvelle structure
  • Services conteneurisés et démarrés avec Docker Compose
  • Chaîne CI/CD industrialisée

Le même socle a ensuite été appliqué à AccèsCash, la plateforme de retraits et de dépôts utilisée par les agents cashpoint.
